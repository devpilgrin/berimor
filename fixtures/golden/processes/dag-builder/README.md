# DAG-builder (волна M)

`tools/dag-builder.html` — однофайловый визуальный конструктор процессов
(без сборки и зависимостей): узлы-шаги, связи (seq/branch/parallel),
боковая форма полей ТОЧНО по StepKind (crates/berimor-types/src/step.rs —
deny-unknown, неизвестное поле отвергается парсером), валидация графа
(дубли id, висячие ссылки, пустые branch/parallel), экспорт в berimor
YAML, сохранение/загрузка проекта JSON.

`support-flow.yaml` — образец формата экспорта: парсится боевым
бинарником (исполнение упирается в контракты — ожидаемо, см. config-
контракты 0.28.0).
