# Пример: контракт из конфигурации (0.28.0)

Процесс `minutes.yaml` извлекает протокол встречи контрактом
`MeetingMinutes`, объявленным оператором в `contracts.toml` (без
пересборки бинарника). Прогон:

```sh
# положить contracts.toml как .berimor/config.toml рабочей директории
# (или слить со своим локальным конфигом — секция [[contracts]])
berimor run minutes.yaml --input '{"text": "Встреча 14.08. Решили: Иван готовит стенд до пятницы, Мария пишет инструкцию."}'
```

Результат — валидированный по схеме объект в `state.minutes`.
