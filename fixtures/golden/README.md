# Golden Fixtures

Примеры, на которых пишутся контрактные тесты (`process-engine.md` §7, `mediation.md` §6) и офлайн-оценка (`ideal-agent-architecture.md` §3.11). Не мок-данные для одного теста — источник истины для многих тестов сразу, версионируется вместе с кодом.

- `processes/` — примеры декларативных процессов (граф шагов).
- `contracts/` — примеры схем Mediation-контрактов.
- `malicious-inputs/` — вводы, которые обязаны быть отклонены Mediation/Capability, а не пройти случайно.

Каждый новый компонент, добавляемый по `ROADMAP.md`, обязан приложить фикстуру сюда прежде, чем его контрактный тест будет считаться осмысленным.
