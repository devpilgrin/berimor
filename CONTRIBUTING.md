# Contributing

## Откуда брать задачу

1. Открыть [`docs/ROADMAP.md`](docs/ROADMAP.md) §20 — актуальный, проверенный по коду список того, что реально осталось (маскировщик секретов закрыт S5, дальше по приоритету — jail-wiring S2, локальный инференс E4, интеграция графа сущностей в `berimor run`, остаток техдолга MEDIUM/LOW). §2 — граф фаз целиком: Milestone 0 (§3), Milestone 1 (§18), Фазы 1 и 6–10 закрыты полностью; таблицы фаз 2–5 (§6–9) могут показывать не проставленные ✅ даже там, где код давно готов — не полагаться на них без проверки, см. §20.1.
2. Взять подзадачу, чьи зависимости («Зависит от») уже закрыты — порядок внутри фазы не строгий, если явная зависимость не указана.
3. Столбец «Класс» в таблице подзадачи — сигнал сложности и требуемого уровня суждения (терминология из `ADR-0010`), а не буквальное указание «эту задачу обязана написать модель». Он одинаково полезен человеку-контрибьютору: **XL** значит «не торопиться и продумать обходы», не только «нужна сильная модель».
4. Подзадачи сложности **XL** обязательны к независимому ревью до мержа — см. `docs/ROADMAP.md` §16. Не мержить в одиночку даже если тесты зелёные.

## Прежде чем писать код

Читать в этом порядке:
- Раздел `docs/arch/*.md`, указанный в столбце «Источник» подзадачи — принцип и контракт.
- Соответствующий `docs/ADR/000N-*.md`, если подзадача связана с конкретным решением — контекст и отклонённые альтернативы объясняют, почему нельзя сделать иначе.
- `docs/arch/views/quality-attributes.md` — какой проверяемый сценарий подзадача обязана удовлетворять.

## Definition of Done

См. `docs/ROADMAP.md` §15 — общее условие для всех подзадач плюс специфика по фазам. Коротко: `cargo check --workspace` проходит, есть тест на фикстуре из `fixtures/golden/`, doc-комментарий модуля ссылается на источник.

## Локальная разработка

```sh
# Rust-ядро
cargo check --workspace
cargo test --workspace
cargo clippy --workspace -- -D warnings

# Bootstrap (TypeScript)
cd bootstrap
npm install --ignore-scripts
npm run build
npm install   # теперь postinstall находит dist/
```

## Коммиты и PR

- Ссылаться на ID подзадачи ROADMAP (например `P3`) и/или ADR в описании PR — заполнить шаблон PR.
- Если подзадача меняет уже принятое архитектурное решение — новый ADR со статусом «Заменяет ADR-000N», не правка старой записи задним числом (`docs/ADR/README.md`, «Формат записи»).
- Новый компонент без фикстуры в `fixtures/golden/` не мержится — см. Definition of Done.
