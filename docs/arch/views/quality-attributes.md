# Quality Attributes — нефункциональные требования и сценарии проверки

> arc42 §10. Каждая строка — проверяемый сценарий, а не общее пожелание («быстро», «надёжно»).

| Атрибут | Сценарий (стимул → контекст) | Ожидаемая реакция | Как проверяется | Связано с |
|---|---|---|---|---|
| Отказоустойчивость | Процесс падает между двумя шагами | Следующий запуск продолжает с последнего события журнала; ни один шаг не теряется и не дублируется | Property-тест: свёртка журнала = живое состояние для любой точки прерывания (`process-engine.md` §7) | ADR-0001, I7 |
| Воспроизводимость | Инцидент нужно расследовать через полгода | Любой прогон воспроизводится свёрткой событий без обращения к модели | Fault injection + replay в CI | ADR-0012, I7 |
| Безопасность (деструктив) | Модель или инъекция генерирует разрушительное действие | Блокируется безусловно до исполнения, независимо от подтверждения | Contract-тест deny-таблицы на золотом наборе запрещённых операций | ADR-0007, I6 |
| Безопасность (утечка) | Секрет присутствует в контексте задачи | Не покидает границу маскировщика ни в одном логе/подтверждении/записи памяти | Тест на всех четырёх точках маскировки (`mediation.md` §4.3) | ADR-0026 |
| Портируемость | Один и тот же CodeAct-шаг на разных ОС/архитектурах | Идентичное поведение, идентичные лимиты ресурсов | Матрица CI: сборка + smoke-тест на каждую платформу перед промоушеном канала (`deployment.md` §8) | ADR-0022 |
| Устойчивость к деградации модели | Провайдер деградирует (растёт доля отказов Mediation) | Автоматическое понижение класса + переключение по заранее заданной цепочке | Телеметрия отказов по (процесс, шаг, модель, версия контракта) (`mediation.md` §6) | ADR-0010, ADR-0011 |
| Управляемость стоимости | Шаг вызывает дорогого удалённого провайдера сверх бюджета | Прерыватель `cost_budget` останавливает шаг детерминированно | Контрактный тест на превышение бюджета | ADR-0011 |
| Латентность CodeAct | Программа выполняет тяжёлые вычисления | Ограничена метрикой топлива Wasmtime, а не wall-clock таймаутом (без флуктуаций от GC/JIT-разогрева) | Нагрузочный тест песочницы | ADR-0020, ADR-0022 |
| Целостность цепочки поставок | Скачан платформенный артефакт для обновления | Не исполняется без успешной верификации подписи по закреплённому `signer_identity` | Fault injection: подделанная подпись → fail closed | ADR-0018, ADR-0026 |
| Отказ от понижения версии | Источник сообщает версию ниже установленной | Отклоняется безусловно без явного подтверждённого события отката | Contract-тест downgrade-попытки | ADR-0012, `deployment.md` §8 |
| Защита памяти от отравления | Факт с ненадёжным источником предлагается к записи | Понижен по весу при выдаче, конфликт — событие человеку, не тихая перезапись | Тест дедупликации на противоречащих фактах | ADR-0005 |
| Auditability | Любое действие системы подвергается ревью | Восстановимо по журналу: кто, что, когда, по какому контракту, по какому подтверждению | Периодическая агрегация событий безопасности (`security-model.md` §5) | ADR-0007 |
| Развёртываемость | Установка на новой машине | Один самодостаточный артефакт, без обязательных внешних сервисов | Проверка отсутствия сетевых зависимостей ядра в изолированном окружении | ADR-0006, I5 |
