# ADR-0025: TypeScript с минимумом зависимостей для bootstrap-слоя

**Статус:** Принято
**Дата:** 2026-07-29

## Контекст

Bootstrap-слой — единственная часть системы, которая обязана существовать в npm-экосистеме (см. ADR-0017). Именно на этапе `npm install` находится крупнейшая типовая поверхность атаки цепочки поставок для npm-пакетов в целом (`deployment.md` §9).

## Решение

TypeScript, минимум внешних пакетов. Bootstrap отвечает только за определение платформы, загрузку и атомарную распаковку артефакта. Проверка подписи не дублируется на JS: bootstrap вызывает подкоманду верификации того же Rust-бинарника (`agent verify <file>`) вместо переизобретения криптографии на другом языке.

## Альтернативы

- **Полноценная реализация криптографической верификации на TypeScript через существующие npm-пакеты** — отклонено: две независимые реализации одной и той же проверки безопасности на разных языках имеют больше шансов разойтись или устареть по отдельности, чем одна реализация, разделяемая между bootstrap-слоем и рантаймом ядра.

## Последствия

Минимальность зависимостей bootstrap-пакета напрямую снижает поверхность атаки транзитивных зависимостей на этапе установки — цена в том, что верификация первого артефакта зависит от наличия в нём же подкоманды `verify`, доверенной к выполнению до полной проверки остального содержимого.
