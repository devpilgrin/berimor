## Формат записи

```
# ADR-XXXX: Заголовок решения

**Статус:** Принято
**Дата:** YYYY-MM-DD

## Контекст
Что заставило принимать решение.

## Решение
Что выбрано.

## Альтернативы
Что рассмотрено и отклонено, с причиной.

## Последствия
Что это даёт и чем приходится платить.

## Связанные документы
Ссылки на arch/*.md.
```

Новое архитектурное решение — новый файл с следующим номером; существующие записи не переписываются задним числом. Если решение пересматривается, старая запись помечается статусом «Заменено» со ссылкой на новую, а не удаляется.
