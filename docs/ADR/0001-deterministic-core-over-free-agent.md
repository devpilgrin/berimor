# ADR-0001: Детерминированный остов вместо свободного агентного цикла как основной режим выполнения

**Статус:** Принято
**Дата:** 2026-07-29

## Контекст

Ключевой архитектурный выбор: кто решает маршрутизацию задачи, ветвление процесса и порядок действий — код или модель. Три независимых наблюдения подталкивают к одному ответу (см. `ideal-agent-architecture.md` §0): промышленная практика показывает, что задачи, которые можно расписать заранее, надёжнее и дешевле выполняются предопределёнными конвейерами, чем свободным агентом; зрелые платформы построения агентов сошлись к конечному автомату с состоянием, а не к свободному диалогу модели с инструментами; анализ отказов агентных систем показывает, что катастрофические классы дефектов живут в инфраструктуре и доверии к входным данным, а не в качестве рассуждений модели.

## Решение

Process Engine — направленный граф шагов с ограниченным набором типов (`sequential/parallel/loop/branch/tool/llm_structured/codeact/agent_step/human_gate/checkpoint`) — основной способ выполнения структурированных задач. Свободный агентный цикл (Agent Loop) остаётся, но только как явный шаг `agent_step` или явный пользовательский люк; вход в свободный режим детерминирован (запрос пользователя, команда, явный шаг процесса) — никогда не решение модели по ходу работы.

## Альтернативы

- **Полностью свободный агентный цикл как единственный режим** — отклонено: непредсказуем, не тестируется целиком; произвольный граф, дорисовываемый моделью на ходу, не поддаётся контрактным тестам на золотых наборах.
- **Свободный DSL без ограничения набора типов шагов** — отклонено: выразительность оправдана только там, где план нельзя написать заранее; для большинства прикладных задач это не так, а цена — непредсказуемость композиции.

## Последствия

Большинство задач выполняется без свободного агента — дешевле, воспроизводимо, тестируемо. Цена — часть задач, для которых процесс нельзя расписать заранее, требует явного люка со более слабыми гарантиями (лимиты ходов и бюджет токенов вместо полного контроля над каждым шагом).
