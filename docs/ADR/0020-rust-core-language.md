# ADR-0020: Rust как язык детерминированного ядра

**Статус:** Принято
**Дата:** 2026-07-29

## Контекст

Нужен язык реализации для Process Engine, Mediation, Context Engine, Capability, Actors/Scheduler и хоста CodeAct-песочницы — такой, в котором структурные инварианты (I1: код решает ветвление; I3: закрытые схемы контрактов; I6: структурная, а не списковая изоляция; I7: один писатель состояния на инстанс) проверяются компилятором, а не только тестами и код-ревью.

## Решение

Rust — для всего детерминированного ядра.

Решающие технические доводы:
- **Исчерпывающий `match`** делает забытый case в ветвлении процесса ошибкой компиляции, а не тихим падением в `default` в рантайме — прямое усиление I1.
- **`#[serde(deny_unknown_fields)]`** — часть определения типа контракта, а не отдельная runtime-проверка, которую можно забыть написать на новом контракте — прямое усиление I3.
- **`Send`/`Sync`** делают конкурентный доступ к общему состоянию без синхронизации ошибкой компиляции, а не багом, который обнаруживает только тест с гонкой, — прямое усиление правила «один писатель состояния на инстанс процесса» (`process-engine.md` §4).
- **Wasmtime** (хост-рантайм CodeAct-песочницы) написан на Rust; встраивание из Rust не требует перехода через FFI-границу между хостом и рантаймом — вся цепочка от host-функций (capability-гейты) до WASM-инстанса memory-safe end-to-end.

## Альтернативы

- **Go** — отклонено как основной: `wazero` (чистый Go WASM-рантайм без cgo) уступает Wasmtime по производительности на вычислительно тяжёлых CodeAct-шагах («смержи 12 таблиц, посчитай агрегаты» — прямая цитата примера из `executors.md` §6); `switch` не обязан быть исчерпывающим — слабее усиливает I1, чем Rust; гонки обнаруживаются `go test -race` (тестом), а не компилятором.
- **C++** — отклонено: встраивание Wasmtime через его C API возвращает в самое чувствительное место архитектуры (границу доверия CodeAct-песочницы) memory-unsafe язык — ровно тот класс ошибок (переполнение буфера, use-after-free), ради устранения которого структурная изоляция через WASM вообще выбиралась.
- **Node.js/TypeScript** — отклонено для ядра: рантайм в сотни МБ на каждый платформенный артефакт нарушает I5; модель `npm install` с исполнением произвольных скриптов — поверхность атаки, зафиксированная в `deployment.md` §9 («вредоносный `postinstall`»), которой у статически собранного Rust-бинарника структурно не существует.

## Последствия

Выше порог входа и медленнее первая итерация разработки, чем на Go или TypeScript. Цена платится один раз (обучение команды) в обмен на компилятор, механически отклоняющий ровно те классы ошибок, которые сама архитектура объявила недопустимыми через инварианты I1, I3, I6, I7.
