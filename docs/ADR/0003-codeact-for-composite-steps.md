# ADR-0003: Генерация программы (CodeAct) для составных шагов вместо цепочки одиночных вызовов инструментов

**Статус:** Принято
**Дата:** 2026-07-29

## Контекст

Композитные задачи (циклы, условия, агрегация по нескольким инструментам) через цепочку одиночных вызовов инструментов требуют многих обращений к модели с накоплением ошибок на каждом шаге.

## Решение

Для таких шагов модель пишет программу (не вызывает инструменты по одному); программа проходит статическую проверку (белый список импортов/имён), исполняется в изоляции, единственный выход — значение, валидируемое Mediation по контракту шага.

## Альтернативы

- **Цепочка одиночных `tool`-вызовов с ретраями на каждом** — отклонено: больше обращений к модели, накопление ошибок на многошаговых задачах, хуже подходит слабым моделям.
- **Планирование через модель-оркестратор, вызывающую подагентов** — отклонено: нарушает I1 (см. ADR-0004).

## Последствия

Независимые замеры показывают, что именно в режиме генерации кода модели с открытыми весами достигают паритета с проприетарными — важно для локального инференса. Цена — необходимость изолированной среды исполнения (см. ADR-0022) и допуск по классам моделей (слабый класс — только `StructuredLLM`, см. ADR-0010).
