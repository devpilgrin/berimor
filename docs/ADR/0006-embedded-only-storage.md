# ADR-0006: Только встраиваемое хранилище, без обязательных внешних сервисов (I5)

**Статус:** Принято
**Дата:** 2026-07-29

## Контекст

Система должна разворачиваться одним артефактом с минимумом внешних зависимостей.

## Решение

Всё хранение — встраиваемое: журнал событий на ключ-значение, полнотекстовый индекс, векторный индекс живут в процессе агента. Внешние СУБД не требуются ни для одного слоя памяти.

## Альтернативы

- **Внешняя СУБД общего назначения (реляционная или документная как отдельный сервис)** — отклонено: нарушает I5, добавляет обязательную внешнюю зависимость и точку отказа на этапе развёртывания и обновления.

## Последствия

Проще эксплуатация (один процесс, данные в одном месте), но накладывает жёсткое ограничение на выбор конкретной технологии хранения — годится не любая БД, только та, что действительно embeddable без сетевого сервера (см. ADR-0021 для конкретного выбора).
