# ADR-0007: Эшелонированная защита (L0–L8) с безусловным deny (I6)

**Статус:** Принято
**Дата:** 2026-07-29

## Контекст

Классы угроз независимы друг от друга — деструктивные команды, SSRF, инъекция инструкций, отравление памяти, эмерджентная координация между акторами. Ни один единый механизм не покрывает все.

## Решение

Девять слоёв защиты от входа до наблюдения (L0–L8), каждый закрывает свой класс угрозы своим механизмом. Deny-статика (I6) — безусловна: подтверждение человека не может отменить срабатывание безусловного запрета ни при каких обстоятельствах.

## Альтернативы

- **Единая точка проверки перед исполнением (один общий гейт на всё)** — отклонено: разные угрозы требуют разного механизма (статический анализ действия vs сетевой гейт vs маскировщик секретов), один универсальный гейт стал бы либо слишком грубым, либо непроверяемо сложным для тестирования.
- **Deny, отменяемое подтверждением «доверенного» пользователя** — отклонено: превращает безусловный запрет в условный, что и есть нарушение I6 по определению — тогда это уже не deny, а ещё один режим подтверждения.

## Последствия

Больше отдельных мест для тестирования (каждый слой — своя контрактная проверка), но отказ одного слоя не равен отказу всей защиты в целом.
