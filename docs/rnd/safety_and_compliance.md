# Безопасность, compliance и нейросимволические агенты

> Раздел основан на переработке материалов из `qrnd.md` и прямой проверке источников.

## Neuro-Symbolic Agents for Regulated Process Automation

- **Title:** Neuro-Symbolic Agents for Regulated Process Automation: Challenges and Research Agenda
- **arXiv:** 2606.13405v2 (June 2026)
- **Authors:** Alexander Rombach, Chantale Lauer, Nijat Mehdiyev
- **Categories:** cs.AI, cs.MA
- **Link:** https://arxiv.org/abs/2606.13405v2

### Суть подхода

В регулируемых отраслях (фарма, качество, клинические процессы) LLM-агенты начинают автоматизировать процессы, требующие суждений. Авторы предлагают парадигму **compliance-by-construction**: символические структуры — регуляции, типизированные процессные модели, ограничения compliance — должны стать не внешними guardrails, а **ядром архитектуры**, определяющим поведение агента.

### Архитектура

```
┌─────────────────────────────────────────────────────────────┐
│  Процессная модель (BPMN/SOP) + формальные контракты шагов  │
├─────────────────────────────────────────────────────────────┤
│  Медиационный интерфейс                                     │
│  • переводит спецификацию шага в prompt для LLM             │
│  • валидирует выход LLM перед переходом к следующему шагу    │
├─────────────────────────────────────────────────────────────┤
│  LLM-интерпретатор неструктурированных данных                │
├─────────────────────────────────────────────────────────────┤
│  Память: STM (текущий случай) + LTM (Case Graph)            │
└─────────────────────────────────────────────────────────────┘
```

- **STM (Short-Term Memory)** — гипотезы и факты по текущему случаю.
- **LTM (Long-Term Memory)** — `Case Graph`, граф знаний сущностей: отклонения, партии, поставщики, корректирующие мероприятия. Позволяет запрашивать исторические прецеденты.
- **Медиационный интерфейс** — ключевой компонент: гарантирует, что выход LLM соответствует формальному контракту шага, прежде чем процесс продолжится.
- **Uncertainty-oriented autonomy** — калиброванная оценка уверенности LLM используется риск-фреймворком для определения уровня человеческого контроля. Низкая уверенность → повышение риска → обязательный человек в контуре.

### Пять исследовательских проблем

| Уровень | Проблема | Суть |
|---------|----------|------|
| Фундаментальный | Regulatory operationalization | Перевод регуляций в исполняемые процессные модели |
| Фундаментальный | Symbolic process grounding | Привязка шагов процесса к данным и действиям агента |
| Возможностей | Uncertainty-oriented autonomy | Управление автономией по калиброванной уверенности |
| Возможностей | Symbolic process memory | Долгосрочная память в виде Case Graph и онтологий |
| Возможностей | Cross-boundary explainability | Объяснимость между символьным и нейронным слоями |

### Связь с регуляторикой

Авторы явно связывают подход с EU AI Act (вступает в силу 2 августа 2026): высокорисковые системы требуют встроенных механизмов человеческого контроля и управления рисками. Compliance-by-construction — архитектурный способ удовлетворить требования, а не только постфактум аудит.

### Практический вывод для проектов

- Guardrails важны, но недостаточны для регулируемых доменов.
- Символические процессные модели должны ограничивать пространство действий агента, а не только проверять результат.
- Уверенность LLM должна быть калиброванной и влиять на эскалацию к человеку.
- Память должна быть структурированной (граф знаний), а не только эмбеддинг-ретривал.

## Сравнение подходов: guardrails vs compliance-by-construction

| Аспект | Guardrails (постфактум) | Compliance-by-construction |
|--------|-------------------------|----------------------------|
| Когда проверяется | После действия агента | Перед переходом к шагу, в архитектуре |
| Пространство действий | Широкое, ограничено правилами | Уже ограничено формальной моделью |
| Ошибки | Ловит семантические | Предотвращает структурные/процессные |
| Требования | Проверка политик | Верификация процесса |
| Человек в контуре | При срабатывании guardrail | По уровню риска/уверенности |
