# ADR-0017: Дистрибуция через npm-bootstrap + платформенные артефакты на GitHub Releases

**Статус:** Принято
**Дата:** 2026-07-29

## Контекст

Нужен способ раздачи кросс-платформенного агента с минимальной поверхностью атаки на этапе установки и без необходимости раздавать все платформенные сборки сразу всем пользователям.

## Решение

Тонкий npm-пакет как установщик: определяет платформу, читает доверенный список, оркестрирует само-обновление. Тяжёлые собранные под конкретную ОС/архитектуру артефакты публикуются на GitHub Releases того же репозитория, не в npm-реестре.

## Альтернативы

- **Публикация всех платформенных бинарников как npm `optionalDependencies`** — отклонено: раздувает npm-реестр тяжёлыми артефактами сразу под все платформы, тогда как нужная версия известна только после определения ОС на конкретной машине пользователя — до этого момента скачивать всё для всех бессмысленно.

## Последствия

Два источника артефактов вместо одного (npm-реестр + GitHub Releases) — чуть сложнее эксплуатация релизного процесса и синхронизация версий между ними, но по каждому каналу передаётся только то, что он реально рассчитан раздавать.
