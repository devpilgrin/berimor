# ADR-0023: MCP как протокол инструментов

**Статус:** Принято
**Дата:** 2026-07-29

## Контекст

Архитектура требует двунаправленный протокол инструментов: система одновременно клиент внешних серверов инструментов и сервер собственных инструментов/ресурсов/шаблонов по тому же стандарту (`ideal-agent-architecture.md` §3.9).

## Решение

MCP (Model Context Protocol) — конкретная реализация этого требования: готовый открытый стандарт именно такой двунаправленной формы.

## Альтернативы

- **Собственный протокол под конкретный проект** — отклонено: заново решает уже решённую задачу, создаёт адаптер, который придётся поддерживать в одиночку, и не даёт бесплатной совместимости с уже существующей экосистемой серверов инструментов.

## Последствия

Совместимость с существующей экосистемой серверов инструментов «бесплатно» — взамен зависимость от эволюции внешнего стандарта, изменения которого нужно отслеживать и учитывать при обновлении ядра.
