# ADR-0024: llama.cpp для локального инференса

**Статус:** Принято
**Дата:** 2026-07-29

## Контекст

Локальный класс моделей в Model Pool должен работать без обязательного внешнего сервиса — требование I5 распространяется и на инференс, не только на хранение.

## Решение

`llama.cpp` через Rust-биндинги, GGUF-формат весов, встроено в основной процесс агента — без отдельного поднимаемого рядом сервера инференса.

## Альтернативы

- **Отдельный локальный сервер инференса, поднимаемый как соседний процесс** — отклонено: лишний процесс, которым нужно управлять на этапе развёртывания и обновления (запуск, отслеживание здоровья, перезапуск при сбое) — нарушает дух «один самодостаточный артефакт», даже формально не будучи внешним сетевым сервисом.

## Последствия

Компактные GGUF-модели ограничены возможностями экосистемы форматов и квантования `llama.cpp`, но встраивание безопасно, без открытого сетевого порта и без отдельного жизненного цикла процесса, который нужно синхронизировать с обновлением самого агента.
