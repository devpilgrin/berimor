# ADR-0005: Четырёхслойная память с записью только через дедупликацию

**Статус:** Принято
**Дата:** 2026-07-29

## Контекст

Данные агентной системы различаются по времени жизни и требуемому уровню доверия: промежуточные результаты задачи, журнал навсегда, извлечённые факты и уроки, процедуры. Общая недифференцированная память в мультиагентных системах — задокументированный вектор атаки (отравление памяти вредоносным вводом через общий канал).

## Решение

Рабочая / эпизодическая / семантическая / процедурная память, с разными правилами записи и жизненным циклом. Запись в семантический слой — только через Mediation-контракт «предложение факта» (субъект, предикат, объект, уверенность, источник) с последующей дедупликацией: точное совпадение → близкое по эмбеддингу → слияние или новая запись. Противоречие новому факту — конфликт-событие человеку, не тихая перезапись.

## Альтернативы

- **Единый недифференцированный лог без слоёв** — отклонено: невозможно применять разные политики доверия и устаревания к данным с разным жизненным циклом.
- **Прямая запись модели в память без дедупликации** — отклонено: открывает канал отравления памяти — вредоносный факт, один раз записанный, выдаётся всем последующим задачам.

## Последствия

Каждая запись факта дороже (проходит контракт + дедупликацию), но защищена от отравления и не накапливает дубликаты бесконтрольно.
